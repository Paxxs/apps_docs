# BeeBolt

BeeBolt is a LAN file manager built for iPhone and iPad. Organize files on the go, or turn on LAN sharing to manage the same files directly from a computer browser with a mouse and keyboard. Its built-in tabbed browser lets you save, organize, compress, or send resources you find online to another device without leaving the app. No cable required.

## Organize files on your device

In BeeBolt’s Files tab, you can create folders, search by name, and select several items to move, copy, or delete together. Tap a file to preview files in a variety of formats, share it, or export a copy. To send several files together, compress the entire folder into an archive. You can also extract archives you receive.

In Apple’s Files app, open the **BeeBolt** folder under **On My iPhone** or **On My iPad** to see the same files. Documents you copy there from iCloud Drive also appear in BeeBolt.

## Use a desktop-class file manager over Wi-Fi

1. Open the Sharing tab in BeeBolt and turn on **LAN Sharing**.
2. Connect your computer to the same Wi-Fi network and open the link from BeeBolt in your browser. You can also open it on a tablet or phone.
3. Upload or download files, or organize the folders on your device directly in the browser.

The default Modern interface provides a desktop-class file manager with a sidebar and a choice of list or grid view. Drag files to move them, right-click to rename an item, or use multi-select and keyboard shortcuts to organize several files at once. You can also create folders, copy files, and create or extract ZIP archives. Classic offers a simpler interface for quick transfers. The web uploader accepts individual files.

The sharing link includes an access code. Anyone with the link can manage your files while sharing is on. Keep BeeBolt in the foreground during transfers. Turning sharing off immediately deactivates the link.

## Tabbed browser

Switch between tabs, bookmark sites, and search your browsing history. Long-press a file link to download it. When the server supports it, segmented transfers run in parallel to accelerate the download. Use the download list to check progress, pause, or resume.

BeeBolt requires iOS or iPadOS 17.1 or later. For details on file storage, network connections, and permissions, see the [privacy policy](/docs/beebolt/privacy).
