# BeeBolt

> 多标签浏览器、多线程下载器与桌面级文件管理器——所有文件都能在系统「文件」App 中访问，也能在同一 Wi-Fi 下的任意浏览器里管理。

BeeBolt 为「文件比网页本身更重要」的场景而做。浏览时找到的东西，可以就地保存、整理、压缩，或直接交给另一台设备，不必离开应用，也不用找数据线。

## 一个真正能留住位置的浏览器

浏览器是一套完整的多标签工作区，而不是只挂了一个下载按钮的网页视图：

- 同时打开多个标签页，随时切换，也可以从标签总览关闭
- 自动记录浏览历史并支持搜索；常去的网站可以加入书签
- 选择默认搜索引擎，或添加自己的搜索引擎
- 移动版排版不够用时，请求桌面版网站
- 选择主题强调色，并在确定前预览外观
- 自行决定是否记住网站登录状态，并可随时清除历史、缓存与 Cookie

## 下载过程一目了然

浏览器能保存的内容都交给同一套下载引擎：

- 长按链接，或粘贴 HTTP、HTTPS 地址新建任务
- 查看每项任务的进度、已传输字节与实时速度
- 暂停、继续、重试、取消，也可以对整个列表批量暂停或继续
- 服务器支持 HTTP Range 时最多四段并行传输，不支持时回退为单连接
- 默认保存到应用内，也可以通过系统选择器指定其他文件夹

「下载列表」标签页是可选的。隐藏后，仍可从浏览器工具栏一键进入下载列表，已完成的文件也始终保留在「文件」中。

## 需要时才显示页面资源

设置中提供可选的 **「探索者」** 模式。开启后，浏览器菜单会多出 **「洞察」** 入口，列出当前页面提供的文件与媒体，方便直接挑选，不必翻查网页源码。「探索者」默认关闭，普通浏览与链接下载都不依赖它。

## 是文件管理器，不是文件列表

「文件」页面是应用 Documents 目录的完整工作区：

- 新建文件夹、重命名、移动、复制、删除，并支持多选
- 按名称搜索，按升序或降序排序
- 就地预览系统支持的格式，再分享或导出
- 从其他应用导入文件，或从照片图库选择照片与视频
- 把文件或文件夹压缩为 ZIP，并在防止路径穿越的前提下解压 ZIP
- 在列表底部查看文件夹数、文件数与总大小

## 每个文件都在系统「文件」App 里

BeeBolt 通过系统文档提供器开放自己的 Documents 目录。在「文件」App 中打开 **我的 iPhone/iPad → BeeBolt**，就能看到同一批文件。把文件从「文件」、其他应用或 iCloud Drive 拷贝进这个文件夹，它也会出现在 BeeBolt 里。

这正是 BeeBolt 不像一个封闭沙盒、更像设备上一个普通文件夹的原因。不需要先导出。

## 桌面级的局域网互传

「共享」页面会把设备变成局域网内的临时文件服务器：

1. 打开 **局域网共享**
2. 在同一 Wi-Fi 下的电脑、平板或手机上打开生成的链接
3. 直接在浏览器里管理文件，无需安装任何配套应用

链接本身已包含访问口令，打开即可使用。在网页界面中可以上传、下载文件，新建文件夹、重命名、移动、复制、删除，以及压缩和解压 ZIP。

提供两种网页风格：

- **现代**——默认。带侧边栏、列表与网格视图、拖放、右键菜单、多选和键盘快捷键的桌面级文件管理器。
- **怀旧**——更简洁的页面，适合快速传输。

共享期间屏幕保持常亮，并提供黑屏模式应对长时间传输。应用离开前台后共享即停止；关闭共享后链接立即失效。

## 内置媒体处理

在设置中开启「探索者」后，浏览器可以列出当前页面提供的媒体和文件，无需翻阅网页源码就能挑选视频或附件。媒体下载与转码由内置的 FFmpeg 引擎在设备本地完成。

## 隐私要点

- 无需 BeeBolt 账号、登录、订阅或内购
- 没有数据分析后台、广告后台，也不含第三方统计或广告 SDK
- 浏览与下载直接连接你选择的网站
- 文件、历史、书签和任务信息都留在设备上

完整说明见本栏目下的「隐私政策」页面。

## 系统要求

- 运行 iOS / iPadOS 17.1 及以上的 iPhone 和 iPad
- 局域网互传需要本地 Wi-Fi
- 直链下载需要 HTTP 或 HTTPS 来源

## 需要了解的限制

- 多线程依赖服务器对范围请求的支持，并不保证一定提速
- 续传要求服务器接受范围请求，且文件未发生变化
- 不保证长时间后台传输；大文件建议保持应用在前台
- 局域网共享仅在应用处于前台时运行
- 局域网网页上传只接受单个文件，不支持整个文件夹
- 下载内容需为你有权访问的资源；BeeBolt 不会绕过 DRM、付费墙或网站限制
