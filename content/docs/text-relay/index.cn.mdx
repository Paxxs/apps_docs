# TextRelay

> 为临时文本准备的干净中转站：粘贴、暂存、清理、提取、重组，都不把杂乱格式带进来。

TextRelay 面向那些你现在需要、但又不想收进长期笔记里的文本：验证码、地址、电话号码、链接、搜索词、较长的 AI 提示词，以及通过分享或 OCR 获取的文字。

核心文本处理流程都设计为在你的设备本地运行。应用不需要账号、后端服务或网络连接即可使用。

## 亮点

- 纯文本编辑，避免富文本格式污染内容
- 自动保存近期文本历史
- 本地识别链接、电话号码、地址、日期及相关文本
- 针对中文、日文、韩文和混合语言优化的 Big Bang 短语拆分
- 通过分享扩展和操作扩展从其他应用导入文本
- 使用系统能力在设备本地对图片进行 OCR
- 可设置字体大小、搜索引擎和识别类别

## 本地优先的设计

TextRelay 刻意让核心工作流在没有互联网时也能使用。你的临时文本、导入内容、OCR 结果、历史记录和设置都会留在设备上，除非你主动选择复制、分享，或在其他应用中打开它们。
