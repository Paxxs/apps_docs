## Plain-Text Workflow

Use this page as a quick reference when checking whether TextRelay is doing its core job well:

1. Paste or import a piece of temporary text.
2. Confirm rich formatting is removed and the content stays readable.
3. Use detection results to act on links, phone numbers, addresses, or dates.
4. Split longer text into phrases when you need to recombine only the useful parts.
5. Keep the result local unless you choose to copy, share, search, or open it elsewhere.
