# LastTime

> 记住那些不每天发生的生活维护事项，而不是把它们变成待办清单。

LastTime 是一个安静的生活维护仪表盘，用来记录那些容易从记忆里悄悄溜走的小事：上次理发、上次更换牙刷、上次洗床单、清理冰箱、预约洗牙，或备份照片是什么时候。

它适合想让脑子轻一点的人，而不是又多一个必须服从的效率系统。

## 你忘记的事，通常不是每天都做的事

大多数应用都是为任务、截止日期、习惯和连续打卡设计的。这对紧急工作很有用，但放在普通生活维护上并不合适。

冰箱最近没清理，你不需要一个红色逾期徽章来催你。你需要的是一个安静的地方替你记住事实，告诉你已经过去多久，并让下一步行动变得清楚。

LastTime 不是待办清单，也不是连续打卡工具。它只关注一个问题：

**我上次做这件事是什么时候？**

这个小小的转向会改变整个应用的感受。没有内疚，没有每日压力，也没有虚假的效率表演。只有那些反复出现的生活细节，你终于不用再一直放在脑子里。

## LastTime 为什么不一样

### 面向真实生活的仪表盘

打开应用，你会看到清晰的维护事项首页。每个事项都会显示真正重要的信息：名称、上次完成时间，以及现在是否需要关注。

你可以用它记录：

- 理发
- 更换牙刷
- 清洗床单
- 清理冰箱
- 洗牙
- 体检
- 补充营养品库存
- 备份照片
- 更新密码
- 任何你想记住的自定义生活维护事项

### 安静的关注状态

LastTime 避免制造严格截止日期的压迫感。它不会冲你喊叫，而是根据建议间隔为每个事项给出安静的关注状态。

- 正常，一切都还好
- 即将到来，近期值得留意
- 需要关注，是时候处理了
- 已拖延较久，间隔已经长到值得重视

你得到的是信号，而不是羞愧。这正是重点。

### 点一下就记录今天

完成某件事后，点一下它。LastTime 会立即记录今天。

点错了？可以撤销。需要补记过去某天的完成记录？打开事项历史并记录真实日期。

这个交互刻意做得很轻，因为维护本身已经完成了。应用不应该为了证明你做过这件事，再让你做更多工作。

### 用模板快速开始

空白设置页很容易让好意愿停在那里。LastTime 提供日常模板，让你可以在几秒内从有用的事项开始，然后按照自己的节奏自定义名称、间隔、图标和颜色。

模板只是起点。你的生活维护仪表盘会变成你自己的。

### 历史记录会变成洞察

每次完成都会成为一段私密历史。随着时间推移，LastTime 会帮助你看见单靠记忆难以保留的模式。

- 每个事项的完成历史
- 类似 Git 的日历模式
- 完成之间的间隔趋势
- 长期节奏洞察

这时，应用就不只是提醒工具了。它会成为一份真实生活如何流动的记录。

## 为低压力维护而设计

LastTime 最适合那些重要、但并非每天紧急的周期性活动。

| 与其... | LastTime 帮你... |
| --- | --- |
| 把零散提醒装在脑子里 | 放进安静的仪表盘 |
| 为所有事情创建吵闹任务 | 记录真实的上次完成 |
| 追逐连续打卡 | 理解间隔和节奏 |
| 猜测某件事是否已经太久没做 | 一眼看到关注状态 |
| 一遍遍重建同样的清单 | 从模板开始再自定义 |

结果很简单：脑子里少开几个小标签页。

## 本地优先的设计

你的维护事项名称、完成历史和个人节奏都是私密的生活细节。LastTime 默认采用本地优先设计，不需要账号即可使用。

没有社交层，没有习惯动态，没有公开连续打卡，也没有效率排行榜。

[阅读 LastTime 隐私政策](https://apps.apppro.dev/lasttime/privacy)
