# LastTime

> 記住那些不會每天發生，卻需要定期留意的日常維護事項。

LastTime 是一款靜謐的日常維護儀表板，用來記錄那些容易從記憶中悄然溜走的小事，例如上次理髮、更換牙刷、清洗床單、清理冰箱、預約洗牙，或是備份照片的時間。

它適合想讓思緒輕鬆一些的人，讓你不必再額外服從一套講求效率的管理系統。

[在 App Store 下載 LastTime](https://apps.apple.com/app/id6778527643)

## 你容易忘記的事，通常不會每天發生

大多數應用程式都是為任務、截止日期、習慣與連續打卡而設計。這對緊急工作很有用，但未必適合日常生活中的維護事項。

冰箱最近沒有清理，你不需要一個醒目的逾期標記來催促自己。你需要一個安靜的地方替你記住事實，告訴你距離上次已經過了多久，並讓下一步行動更清楚。

LastTime 是一份待辦清單嗎？它並不以催促完成為目的。它只關注一個問題：

**我上次做這件事是什麼時候？**

這個小小的轉向改變了整個應用程式的感受。沒有罪惡感，沒有每日壓力，也沒有虛假的效率表演。只有那些反覆出現的生活細節，你終於不必一直記在腦中。

## LastTime 為何不同

### 貼近真實生活的儀表板

開啟應用程式後，你會看到清楚的維護事項首頁。每件事項都會顯示真正重要的資訊：名稱、上次完成時間，以及目前是否需要留意。

你可以用它記錄：

- 理髮
- 更換牙刷
- 清洗床單
- 清理冰箱
- 洗牙
- 健康檢查
- 補充營養品庫存
- 備份照片
- 更新密碼
- 任何你想記住的自訂日常維護事項

### 安靜的留意狀態

LastTime 避免營造嚴格截止日期的壓迫感。它不會對你大聲催促，而是根據建議間隔，為每件事項顯示安靜的留意狀態。

- 正常：一切都在預期之內
- 即將到來：近期值得留意
- 需要留意：是時候處理了
- 已延後一段時間：間隔已經長到值得重視

你得到的是提示，而不是羞愧感。這正是重點。

### 輕點一下即可記錄今天

完成某件事後，輕點該項目。LastTime 會立即記錄今天的日期。

不小心點錯了？可以復原。需要補記過去某天的完成記錄？開啟事項記錄並輸入實際日期。

這項互動刻意設計得很輕巧，因為維護工作本身已經完成。應用程式不應該為了證明你做過這件事，再讓你多做一步。

### 使用範本快速開始

空白的設定頁面很容易讓好意就此停住。LastTime 提供日常範本，讓你幾秒內就能從實用事項開始，再依自己的步調自訂名稱、間隔、圖示與顏色。

範本只是起點。你的日常維護儀表板會逐漸成為專屬於你的樣貌。

### 記錄會轉化為洞察

每次完成都會成為一段私密記錄。隨著時間累積，LastTime 會協助你看見單靠記憶難以保留的模式。

- 每件事項的完成記錄
- 類似 Git 的日曆模式
- 完成之間的間隔趨勢
- 長期節奏洞察

到了這個階段，應用程式就不只是提醒工具。它會成為一份記錄真實生活如何流動的資料。

## 本機優先的設計

你的維護事項名稱、完成記錄與個人節奏都是私密的生活細節。LastTime 預設採用本機優先設計，不需要帳號即可使用。

沒有社群層、習慣動態、公開連續打卡，也沒有生產力排行榜。
