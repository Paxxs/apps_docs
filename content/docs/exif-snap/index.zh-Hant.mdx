# ExifSnap

ExifSnap 是一款使用 SwiftUI 開發的跨平台應用程式，可在 iOS 與 macOS 裝置上順暢執行。它面向攝影愛好者與專業使用者，提供簡單直觀的方式來檢視和修改圖片中的 EXIF 中繼資料。

## 主要功能

### 檢視 EXIF 資訊

使用 ExifSnap 時，你可以從照片圖庫中選擇任意圖片，應用程式會立即顯示圖片及其詳細 EXIF 資訊，包括：

- 檔案名稱
- 拍攝日期與時間
- 使用的裝置型號
- 鏡頭資訊
- 焦距參數
- 光圈大小
- 圖片解析度
- ISO 感光度
- 快門速度
- 曝光補償值
- GPS 位置資訊

### 修改 EXIF 資訊

ExifSnap 不僅能檢視圖片中繼資料，也能協助你修改：

1. 選擇要修改的目標圖片
2. 將目前檢視圖片的 EXIF 資訊寫入目標圖片
3. 另存為全新的圖片檔案，原始圖片不受影響

這項功能特別適合需要統一相片資訊，或修正錯誤中繼資料的情境。

## 介面特色

- 採用 SwiftUI 原生設計語彙，介面簡潔美觀
- 符合 iOS 與 macOS 設計規範，提供一致的使用體驗
- 操作流程直觀，無須複雜學習
- 資料處理效率高，處理高解析度圖片時也能保持順暢

## 使用情境

- 攝影師整理作品集時檢視詳細拍攝參數
- 攝影愛好者學習與分析優秀作品的拍攝技巧
- 需要統一管理多張相片中繼資料的專業使用者
- 希望保留或移轉相片原始資訊的使用者

## 平台支援

- iOS 裝置，包括 iPhone 與 iPad
- macOS 電腦

憑藉完善的功能與精心設計的介面，ExifSnap 是管理及運用圖片中繼資料的理想工具。無論你是專業攝影師或攝影愛好者，ExifSnap 都能滿足你對圖片 EXIF 資訊的需求。
