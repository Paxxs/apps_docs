# ExifSnap

ExifSnap 是一款使用 SwiftUI 开发的跨平台应用，可以在 iOS 和 MacOS 设备上流畅运行。它面向摄影爱好者和专业用户，提供一种简单直观的方式来查看和修改图片中的 EXIF 元数据信息。

## 主要功能

### 查看 EXIF 信息

使用 ExifSnap 时，你可以从照片图库中选择任意图片，软件会立即显示图片及其详细 EXIF 信息，包括：

- 文件名
- 拍摄日期和时间
- 使用的设备型号
- 镜头信息
- 焦距参数
- 光圈大小
- 图片分辨率
- ISO 感光度
- 快门速度
- 曝光补偿值
- GPS 位置信息

### 修改 EXIF 信息

ExifSnap 不仅可以查看图片元数据，也可以帮助你修改它：

1. 选择需要修改的目标图片
2. 将当前查看图片的 EXIF 信息写入目标图片
3. 另存为全新的图片文件，原始图片不受影响

这个功能特别适合需要统一照片信息，或修正错误元数据的场景。

## 界面特点

- 采用 SwiftUI 原生设计语言，界面简洁美观
- 符合 iOS 和 MacOS 设计规范，提供一致的使用体验
- 操作流程直观，无需复杂学习
- 数据处理高效，即使处理高分辨率图片也能保持流畅

## 使用场景

- 摄影师在整理作品集时查看详细拍摄参数
- 摄影爱好者学习和分析优秀作品的拍摄技巧
- 需要统一管理多张照片元数据的专业用户
- 希望保留或迁移照片原始信息的用户

## 平台支持

- iOS 设备，包括 iPhone 和 iPad
- MacOS 电脑

凭借强大的功能和精心设计的界面，ExifSnap 是管理和利用图片元数据的理想工具。无论你是专业摄影师还是摄影爱好者，ExifSnap 都能满足你对图片 EXIF 信息的需求。
